# TraderPen

### Desenhe, marque e estude seus gráficos de trading diretamente na tela.

O **TraderPen** é uma ferramenta para Windows criada especialmente para traders que precisam desenhar, marcar e explicar seus estudos diretamente sobre gráficos de trading.

Ele funciona como uma camada sobre a tela, permitindo utilizar ferramentas de desenho sem precisar sair do gráfico, tirar screenshots ou alternar constantemente entre diferentes aplicativos.

> 🎯 Criado pensando no dia a dia do trader.

---

## 🎥 Veja o TraderPen em ação

O TraderPen pode ser utilizado sobre diferentes plataformas e ambientes de análise, permitindo desenhar diretamente sobre o gráfico sem precisar alterar o aplicativo que está sendo utilizado.

---

## 💡 Por que o TraderPen?

Ferramentas genéricas de desenho podem resolver algumas necessidades básicas, mas não foram desenvolvidas pensando especificamente no fluxo de trabalho de quem estuda e opera o mercado.

O TraderPen nasceu justamente dessa necessidade.

A ideia é ter, em uma única ferramenta:

- ✏️ Ferramentas de desenho
- 📊 Elementos específicos para análise de mercado
- 🕯️ Desenho manual de candles
- 📐 Linhas, setas, formas e marcações
- 🟦 FVG, BPR e OB
- 🏷️ Rótulos para estruturas de mercado
- 🗂️ Abas para organizar estudos
- 🧽 Borracha por objeto ou por trecho
- ↩️ Desfazer e refazer
- 🎨 Cores e espessuras
- 🖥️ Modo apresentação
- 📸 Captura e exportação dos estudos

Tudo isso funcionando diretamente sobre a tela.

# ✏️ Principais ferramentas

## Ferramentas de desenho

O TraderPen possui ferramentas para os principais tipos de marcação utilizados durante estudos e análises:

- Caneta
- Marca-texto
- Linha
- Seta
- Path / traçado livre
- Retângulo
- Círculo
- Texto
- Borracha
- Seleção e movimentação

Os objetos podem ser editados depois de desenhados, permitindo ajustar tamanho, posição e formato.

---

## 📊 Ferramentas para análise de mercado

Além das ferramentas tradicionais de desenho, o TraderPen possui recursos pensados especificamente para estudos de trading.

### 🕯️ Candle

Permite desenhar candles manualmente sobre o gráfico.

O TraderPen utiliza um guia visual para ajudar no alinhamento dos candles, facilitando a criação de sequências durante explicações e estudos.

### FVG

Criação rápida de zonas de **Fair Value Gap**.

### BPR

Ferramenta específica para marcação de **Balanced Price Range**.

### OB

Ferramenta para marcação de **Order Block**.

### Estruturas de mercado

As linhas podem receber rótulos específicos para estudos de estrutura, incluindo:

- CISD
- PX
- BoS
- ChoCh
- MSS
- Liquidez
- Linha simples

Isso permite identificar estruturas diretamente no gráfico sem precisar criar manualmente textos separados.

---

# 🗂️ Abas para organizar seus estudos

O TraderPen permite trabalhar com várias abas dentro da mesma sessão.

Você pode, por exemplo:

**Aba 1**
> Estrutura inicial do mercado

**Aba 2**
> Liquidez

**Aba 3**
> FVG + entrada

**Aba 4**
> Explicação completa

Ao criar uma nova aba, o estudo anterior é preservado.

As abas não são apenas imagens estáticas. Os elementos continuam editáveis.

---

# 🧽 Borracha inteligente

O TraderPen possui dois modos de borracha.

### Apagar objeto

Remove o objeto inteiro ao tocar nele.

### Apagar trecho

Funciona de forma semelhante à borracha de um editor de desenho, permitindo apagar apenas uma parte do traçado.

Um preview visual mostra a área que será apagada enquanto você utiliza a ferramenta.

---

# 🎨 Cores e espessuras

O TraderPen possui uma seleção rápida de cores para facilitar as marcações durante o estudo.

Também existem três níveis de espessura:

- Fina
- Padrão
- Destaque

A troca pode ser feita diretamente pela barra de ferramentas.

---

# 🖥️ Overlay

O TraderPen funciona como uma camada sobre a tela.

No **Modo Mouse**, você continua utilizando normalmente o aplicativo que está por baixo.

No **Modo Desenho**, o TraderPen assume a interação com a tela para permitir as marcações.

### F9

Use:

**F9 → alternar entre Modo Mouse e Modo Desenho**

Isso permite alternar rapidamente entre analisar o gráfico e desenhar sobre ele.

---

# 🎬 Modo apresentação

O TraderPen possui um modo de apresentação para deixar a tela mais limpa durante explicações.

A interface da ferramenta pode ser ocultada para que a atenção fique concentrada no gráfico e nas marcações.

Ideal para:

- aulas
- gravação de vídeos
- explicações
- apresentações
- estudos

---

# 📸 Captura e exportação

Os estudos podem ser capturados e exportados para utilização posteriormente.

É possível trabalhar com diferentes opções de fundo, incluindo:

- Transparente
- Branco
- Preto

Isso facilita a utilização das marcações em aulas, vídeos, apresentações e materiais de estudo.

# 🚀 Download

A versão mais recente do TraderPen está disponível na seção **Releases** deste repositório.

Procure pelo arquivo:

**TraderPen-vX.X.X-win-x64.zip**

Baixe o arquivo, extraia o conteúdo e execute o:

**TraderPen.exe**

### Requisitos

- Windows 10 ou superior
- Windows 64 bits (x64)

O TraderPen é distribuído como um aplicativo independente, portanto não é necessário instalar o .NET separadamente.

---

# ⚠️ Primeiro acesso

Como o TraderPen é um aplicativo independente distribuído diretamente pelo desenvolvedor, o Windows Defender / SmartScreen pode apresentar um aviso de segurança durante a primeira execução.

Caso isso aconteça:

**Mais informações → Executar assim mesmo**

Esse aviso pode aparecer porque o aplicativo não possui uma assinatura digital de um certificado comercial.
